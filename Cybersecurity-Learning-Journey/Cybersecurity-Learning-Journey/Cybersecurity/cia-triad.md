# The CIA Triad

The CIA triad is a basic information-security model made up of Confidentiality, Integrity, and Availability. It is used to think about the main security goals for information and systems.

## 1. Confidentiality

Confidentiality means that information is accessible only to authorised people or systems.

**Example:** Access controls help ensure that only approved staff can view restricted student records.

Common ways to support confidentiality include access control, authentication, and encryption.

## 2. Integrity

Integrity means protecting information from unauthorised or improper changes and helping ensure that it remains accurate and complete.

**Example:** A system should prevent unauthorised changes to grades stored in a database.

Controls can include permissions, change tracking, validation, and cryptographic integrity checks.

## 3. Availability

Availability means that systems and information are accessible when authorised users need them.

**Example:** A university service should be maintained so students and staff can use it when required.

Availability can be supported through backups, maintenance, redundancy, and appropriate protection against service disruption.

## Summary

| Principle | Main question |
|---|---|
| Confidentiality | Who can see the information? |
| Integrity | Has the information been changed improperly? |
| Availability | Can authorised users access it when needed? |
