# What Is a Security Operations Center (SOC)?

## Introduction

A Security Operations Center (SOC) is a team or function responsible for monitoring an organisation's systems and investigating potential security events. Its goal is to help detect, understand, and respond to security incidents.

## Common SOC activities

- Monitoring security alerts and system activity.
- Reviewing logs from devices, applications, and network systems.
- Investigating unusual or suspicious events.
- Recording findings and maintaining incident documentation.
- Escalating cases when further investigation or action is needed.
- Working with other technical teams during incident response.

## SOC analyst levels

Organisations use different role structures, but a common model is:

| Level | Typical focus |
|---|---|
| Tier 1 | Initial alert review, triage, and escalation |
| Tier 2 | Deeper investigation and incident analysis |
| Tier 3 | Complex investigations, threat hunting, and advanced analysis |

The exact responsibilities differ between organisations.

## Common SOC technologies

- **SIEM:** collects and helps analyse security events and logs.
- **EDR:** provides visibility and security capabilities for endpoints.
- **Firewalls:** control network traffic according to configured rules.
- **Packet analysis tools:** help inspect network communications.

Examples of SIEM products include Splunk and Microsoft Sentinel. Learning a tool requires understanding the data it uses and the context of its alerts.
